# 2.2.1 — 2026-10-06

**A faster first cue and a cleaner transcript, a week into using 2.2.** Nothing
new to learn; every item here is something that got in the way during real
calls.

## Changed

- **The start modal is shorter.** The "captured / sent / never sent" box that
  repeated what Help and Privacy & Data already say is gone.

## Removed

- **Talk to BrainCue (spoken replies) is hidden.** The push-to-talk shortcut,
  the Cue Card voice bar, the Home card and the Voice output model row are
  gone for now: in a call you do the speaking, and a generated voice playing on
  the same machine only risked leaking into your microphone. The code stays
  behind a flag.

## Fixed

- **The first cue arrives sooner.** Retrieval now starts while the question
  is still being spoken, a Space with no documents no longer pays for an
  embedding call it cannot use, and the answer model's connection is opened
  when the session starts instead of on the first question. Measured on a
  meeting question: the wait from the end of the sentence to the first word
  on the card fell from about 4.5 s to about 2.5 s on both engines. What is
  left is the model's own first token plus the network round trip.
- **The local engine no longer clips the first word of a turn.** After a few
  seconds of silence the local transcriber used to reset itself just as the
  next person started speaking, so "Fine, let's decide next week" arrived as
  "Let's decide next week". That reset is gone.
- **Dropdowns close when you click away.** Clicking outside a model picker
  closed it and immediately reopened it.
- **Dialogs can always be closed.** A tall dialog scrolled under the window's
  title bar left its Close button unclickable; dialogs now start below the
  title bar.
