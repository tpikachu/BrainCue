## Grounding and evidence fixes

G11's exact recognized question, “Would you consider relocation for this role?”,
hit the lexical fallback. Modal/discourse words diluted its memory overlap
below the existing threshold. The relocation memory was not sent. The fix
ignores those question words when ranking; it does not lower the threshold,
change consent/scope, or alter stored memories. Offline regressions include
the exact question, unrelated-query controls, and all 60 General/Technical
fixtures with no interim and stalled semantic retrieval. Live correction
effectiveness has not been measured.

The first report also incorrectly rejected decision evidence. The driver's
summary file contains the real IPC envelope (`summary.summary.decisions`);
the validator expected a bare summary. The validator now accepts that real
shape and legacy bare summaries, rejects ambiguous/incomplete evidence, and
uses the worst warm-block decision summary without inventing a pooled p95.
All 55 hashed raw evidence files are unchanged. Original reports are retained.
Regenerating the report removes only the decoder error; G11 still invalidates it.
