## Interview-first cycle (`feature/interview-copilot-first`)

Product priority changed: Interview Copilot is the primary feature
([00-VISION.md](../00-VISION.md) status note; design of record
[23-INTERVIEW-COPILOT.md](../23-INTERVIEW-COPILOT.md)). Four reviewable commits.

### Baseline (master 3d8d57e)
- 809 tests green, typecheck clean. All five review leads confirmed in code:
  classifier saw one utterance with no context; `onTranscriptFinal` returned
  early while answering; 10-item / 300-char history; follow-up retrieval used
  the generated answer; OpenAI-only defaults and start gate.
- **Root cause of missed questions:** the classify default `gpt-4.1-nano` is no
  longer served (OpenAI retired it 2026-10-23; confirmed against a live
  `/v1/models`). Every classification threw → no automatic answers.

### 1 · Detection + scheduling
Rules decide reliable cases with no model call; the classifier (context, zod,
1.2 s timeout, 5 s late verdicts) decides the ambiguous rest. Explicit
scheduling policy: detect always, one stream at a time, FIFO queue, coalesce
repeats, supersede continuations/corrections on the same card, hold
fragments, missed cards instead of silent drops. "Answer that" button.
Latency instrumentation incl. first VISIBLE content (overlay reports after
paint) → `<userData>/metrics/latency.jsonl`.

### 2 · Context + grounding
`ConversationContext` replaces the history buffer (recent verbatim, compact
earlier record, BM25-recalled turns, open questions, suggestions labelled as
not evidence, referential subject). Follow-ups follow what the candidate SAID.
Resume restores the session's own rows. Prompt ranks sources, labels JD as
employer requirement, treats documents/transcript as data. Résumé/JD source
balance in retrieval.

### 3 · Models + readiness
Provider + Fast/Balanced/Quality → per-task candidates filtered by discovery
(cached `/models`). Catalog capability metadata (efforts, thinking, lifecycle);
live tasks at the lowest effort ("none" on GPT-6). Overrides preserved,
corrected only when they cannot run. One bounded retry before the first token;
unavailable model → next candidate on the same provider. Per-capability
readiness; no OpenAI key required to start; parsing on any chat provider;
lexical retrieval without embeddings; vector read path now identity-filtered.

### 4 · UI
Interview default + first; readiness checklist in the start modal; Cue Card
trimmed (extra controls behind ⋯, compact transcript, duplicate companion bar
and memory editor removed); capture status in the Cue Card.
