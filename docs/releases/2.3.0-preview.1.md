# BrainCue Copilot 2.3.0-preview.1 — Windows preview

This preview brings the interview-first workflow to Windows. It includes
the simpler start flow and Cue Card toolbar, provider-aware model selection,
ordered question handling, searchable conversation context, and improved
History and Resume. See the [full changelog](https://github.com/tpikachu/BrainCue/blob/v2.3.0-preview.1/changelog/2.3.0-preview.1.md).

## Install

Download **BrainCue-Copilot-Setup-2.3.0-preview.1.exe** from the assets below
and run it. The installer is **unsigned**; Windows SmartScreen may warn.
Only Windows is included in this preview. macOS and Linux are not validated
or distributed here.

The installed app shares `%APPDATA%\braincue` with development builds.
Back up your data before upgrading, and run one copy at a time.

Installer: **100,201,300 bytes**. SHA-256:

```text
F1A2151B8B09B5BB563DAAD9E835D296A35191088E3A8FE66EAC1DF1DA263C69
```

## Validation and limits

- The engineer reports 1,369 passing unit tests, 111 passing offline E2E
  cases, clean typecheck/build, and successful Windows install, upgrade,
  fresh-install and data-retention checks. Offline tests use simulated
  providers and do not measure real interview speed.
- **Real interview latency remains unmeasured.** The target is first useful
  words at p50 <=1.5 s and p95 <=3 s, measured separately for General and
  short Technical questions. The controlled user interview and full live
  performance run are still pending.
- The coding solver's time budget is a proposal.
- A document deleted after early retrieval can still ground that answer.
- Memory consent is rechecked immediately before each answer request,
  including prefetched memories. Already-sent input cannot be withdrawn.

This release is explicitly a **prerelease**, with no stable acceptance claim.
**v2.2.2 remains stable**; this preview is not offered as its automatic update.

For a short preview check, try General and short Technical questions, a
follow-up, recall of an earlier fact, then Stop → History → Resume → Stop.
That check can inform preview feedback; it does not close PERF-01.
